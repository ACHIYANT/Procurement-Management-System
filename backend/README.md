# PMS Backend

This backend powers the secure and auditable procurement workflow services for PMS.

## Services

- `AuthService`
- `ProcurementManagementService`

## Current Functional Focus

The procurement service currently centers around:
- Tender
- EMD
- PBG

## Planned Expansion

It is intended to expand into:
- Indent workflow
- Committee workflow
- Negotiation and allocation
- LOA/RC and purchase order lifecycle
- Inspection, delivery, and installation
- Seller invoice, purchase booking, and sale invoice flow
- Approval engine and document-driven compliance tracking
