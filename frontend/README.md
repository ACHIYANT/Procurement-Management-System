# PMS Frontend

This frontend contains the user interface for the Procurement Management System.

It is responsible for:
- authentication-aware protected routing
- role-based screens and workflow visibility
- procurement step forms and detail pages
- committee, EMD, PBG, PO, and compliance views
- large-table rendering with scrollable and sticky-column layouts

## Stack

- React
- Vite
- Tailwind CSS
- React Router

## Development

Run:

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```
